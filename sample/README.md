# Sample: Maple Street Bookkeeping (made up)

Maple Street Bookkeeping is a fictional business. The address, the email, Dana, the phone number 519-555-0142 (555 numbers don't ring anyone), the hours in sample-data.csv, and the florist and its price in prompt-doc.txt are all made up.

This is the exact set we tested live. Drop every file here into a project, paste INSTRUCTIONS.md as the instructions, then send one of the prompts:

| Prompt | What you get |
|---|---|
| prompt.txt | A one-page welcome sheet for new clients |
| prompt-doc.txt | A one-page proposal for a (made up) florist |
| prompt-chart.txt | A chart of where the hours went, on a one-page PDF |

Each comes back as a PDF in about 2 minutes, with a list of what it guessed.

What each file does:
- brand.md, logo.png: the look
- my-writing.md: the voice
- outlines.md: the shapes of documents that worked
- pictures.md + pic-*.png: the only pictures it may use
- chart-guide.md: how charts should look
- sample-data.csv: the numbers for the chart

Once you've seen it work, swap in your own from ../templates.
