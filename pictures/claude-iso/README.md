# Pictures drawn as code, in Claude (about 2 minutes each)

Claude can't paint like ChatGPT, but it writes code that draws. Same picture every time, editable, sharp at any size.

1. claude.ai > Projects > New project.
2. Instructions: paste INSTRUCTIONS.md.
3. Files: upload iso_lib.py and iso_examples.py.
4. Ask: "Draw a contract on a desk with an agent checking it." Then change the subject.

example-contract.svg is what the contract example draws. Code execution has to be on in your Claude settings.
